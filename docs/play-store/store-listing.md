# Google Play store listing

## English (United States)

**App name — 30 characters maximum**

Forgetty

**Short description — 80 characters maximum**

Plan tasks, focus on today, and keep reminders, lists, and tags organized.

**Full description**

Forgetty is a calm, focused task manager for everyday planning.

Capture a task quickly, add notes and subtasks, choose a list or tags, set priority, and schedule a reminder. Use Today to focus on what matters now, or switch to calendar and search views when you need the bigger picture.

Key features:

- Fast task creation with notes, subtasks, priorities, dates, and recurrence
- Today, high-priority, completed, and flexible filter views
- Lists and tags with dedicated management screens
- Search across tasks and task details
- Reminder, due-today, and Today digest notifications
- Calendar and statistics views
- Light, dark, and system appearance
- Guest mode for local use without an account
- Optional Google sign-in for cloud synchronization
- Task export and Android home-screen widgets

Forgetty keeps the interface simple so your tasks stay in focus.

**Полное описание**

Forgetty — спокойный и понятный менеджер задач для ежедневного планирования.

Быстро создавайте задачи, добавляйте заметки и подзадачи, выбирайте списки и теги, задавайте приоритет и настраивайте напоминания. Экран «Сегодня» помогает сосредоточиться на ближайших делах, а календарь и поиск дают полную картину.

Основные возможности:

- Быстрое создание задач с заметками, подзадачами, приоритетами и датами
- Повторяющиеся задачи и напоминания
- Фильтры «Сегодня», «Высокий приоритет» и «Выполненные»
- Управление списками и тегами
- Поиск по задачам и их деталям
- Уведомления о напоминаниях, задачах на сегодня и дневной дайджест
- Календарь и статистика
- Светлая, тёмная и системная тема
- Гостевой режим без аккаунта
- Необязательный вход через Google для синхронизации
- Экспорт задач и виджеты Android

Forgetty оставляет интерфейс простым, чтобы в центре внимания были ваши задачи.
